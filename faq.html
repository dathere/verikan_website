FAQ

Frequently asked questions

Everything you've asked us about verified answers, FAIR data, and how Verikan actually works under the hood.

What is Verikan?

Verikan is datHere's "Agentic Data Concierge" for verifiable knowledge. It operates in the cloud with an on-premises FAIRification option, keeping raw data on your network. Users ask questions and receive Verified Answers. When no previous Verified Answer exists, it employs agentic coding to draft a deterministic Python notebook in a designated GitHub repository for expert review. The name also references a mythical creature from Magistream lore.

What is a Data Concierge? How is it different from a Chatbot?

A chatbot generates the most "probable" answer using language models, even with RAG and tool calls, meaning answers are "synthesized" by the model and potentially subject to hallucinations. A traditional Data Concierge helps users find datasets and points to pre-prepared expert answers without generating its own, effectively eliminating hallucinations.

What is an Agentic Data Concierge? How is it different from a traditional Data Concierge?

An agentic variant creates draft answers using Python notebooks that teams can independently verify through GitHub workflows. It functions as a harness supporting question-to-verified-answer workflows using FAIRified data and inferred ontologies with experts-in-the-loop, substantially reducing hallucinations while leveraging modern agentic coding.

What is FAIR Data?

FAIR stands for "Findable, Accessible, Interoperable & Reusable," defined in a 2016 Scientific Data publication. The principles emphasize "machine-actionability" enabling computational systems to find, access, interoperate, and reuse data with minimal human intervention.

What is FAIRification?

FAIRification is "the process of making your Data Findable, Accessible, Interoperable and Reusable." This typically involves compiling extensive metadata. Verikan uses a fast FAIRification engine powered by qsv, their data-wrangling toolkit, capable of processing large datasets rapidly while computing statistical measures and type inferences.

What is "Opening Data" (as a verb)?

"Opening data is the act of Contextualizing & Humanizing Data by adding High Quality, High Resolution Metadata to make it Useful, Usable & Used by Machines, Agents and Humans alike."

What is a Verified Answer?

A Verified Answer represents a neuro-symbolically compiled response combining neural networks (LLMs) with deterministic Python scripts. Verikan uses FAIRified metadata and corpus-wide ontologies to generate high-quality draft answers leveraging world knowledge and high-value data sources.

What is TypedStandards?

TypedStandards is "an open standard for independent, third-party verification of AI-generated answers," providing cryptographically-signed confirmation that answers remain reproducible and verifiable from their inputs, establishing baseline provenance without attesting correctness.

Where are the Answers stored?

The Answer Library — both draft and verified — resides in an associated GitHub repository that can exist within your organization, granting full administrative rights and ownership.

What Data Portals do you support?

Verikan supports any portal using DCAT standards including CKAN, Socrata, and ESRI, with CKAN receiving additional features given datHere's background.

What Models do you support?

The platform uses OpenRouter supporting 400+ models from 70+ providers including local LLMs. The FAIRification engine supports any OpenAI-compatible API and optimizes for local LLMs to preserve data privacy.

Does Verikan only work with Open Data?

No, it functions with internal data too. Verikan "opens data" by FAIRifying it and storing enriched metadata in a FAIR Shadow Catalog, with data sourced from network-reachable locations like S3, SharePoint, network drives, or data lakes.

What is a FAIR Shadow Catalog?

Verikan stores enriched FAIRified metadata in the Shadow Catalog without retaining raw data post-compilation. Currently housed in a purpose-built database exclusive to Verikan, work progresses toward porting it to an internal CKAN instance.

Can I use all that FAIRified metadata in the FAIR Shadow Catalog outside Verikan?

Yes, once ported to CKAN, users access metadata through familiar CKAN interfaces or APIs, including Datapusher+, neuro-symbolic data dictionaries, visualizations, and inferred ontologies.

Our team already uses Agentic Coding Harnesses. Can Verikan work with them?

Yes, Verikan's architecture supports agentic coding integration, leveraging GitHub mechanisms (issues, pull requests, commit history, reviews) for Answer Library curation using workflows teams already understand.

Is Verikan Open Source?

While components like qsv, its MCP Server, datHere Cowork Plugin, Datapusher+, and CKAN are open source, Verikan itself is not. It operates as a Knowledge as a Service (KaaS) solution, with optional specialized integrations for CKAN PaaS customers.

What is Knowledge as a Service (KaaS)?

According to Wikipedia, KaaS "is a computing service that delivers information to users, backed by a knowledge model." Verikan subscribers receive continuous improvements and access to curated high-value reference data including BLS and FBI Crime Data.

We have very high Security requirements. Can we run Verikan on-premise using only Local LLMs?

Contact datHere. They offer containerized on-premises deployments coordinating with your DevOps team, supporting preferred models and local LLMs while keeping data, FAIRified metadata, and inferences internal.
